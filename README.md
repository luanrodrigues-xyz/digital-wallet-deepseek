# Digital Wallet

Criei esse projeto para testar o DeepSeek com o OpenCode Free. Deixei a IA gerar uma API de carteira digital em Java e depois fui olhar o que tinha saído.

Encontrei alguns problemas e resolvi usar o projeto para estudo. Vou abrindo issues com bugs, falhas de segurança e coisas que dá para melhorar. Quem estiver começando com Java e Spring Boot pode escolher uma delas e tentar corrigir.

**Regra dos desafios: não usar IA para gerar código, testes ou correções.** Pode consultar documentação, pesquisar e perguntar nas issues. A ideia é entender o problema e escrever a própria solução.

## Por onde começar?

1. [Preparar o ambiente e rodar o projeto](docs/getting-started.md)
2. [Testar a API pelo Swagger, Postman ou terminal](docs/api-testing.md)
3. [Ver como contribuir](docs/contributing.md)
4. [Escolher uma issue](https://github.com/luanrodrigues-xyz/digital-wallet-deepseek/issues)

Não precisa esperar ter várias issues abertas. Vou adicionando novos desafios aos poucos.

## Tecnologias

Java 21, Spring Boot, PostgreSQL, Spring Data JPA, Flyway, Maven, JUnit, Testcontainers e Swagger.

## Dúvidas?

Pode perguntar na própria issue, inclusive se não souber por onde começar. A gente pode discutir o problema sem entregar a solução pronta.

> **Atenção:** o código inicial foi gerado por IA e pode conter falhas. É um projeto de estudo, não use em produção nem com dinheiro real.
